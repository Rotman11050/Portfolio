01

RESEARCH INTERNSHIP · AUDIO PROCESSING · MACHINE LEARNING

ELECOM — Elephant Vocalisation Analysis

Developed and extended tools for analysing elephant vocalisations, supporting research into cohesion and coordination calls.

PythonMATLABNumPySciPyscikit-learnPyTorchSpectraLayers
Project details

The workflow combined manual annotation, contour-guided audio filtering, acoustic feature extraction and machine-learning experiments.

Improved a MATLAB annotation tool for tracing calls in spectrograms. Built Python tools for preparing recordings, matching annotations to separated audio and comparing processing methods.

Explored call classification using acoustic features, logistic regression and an EfficientNet-based neural network.
